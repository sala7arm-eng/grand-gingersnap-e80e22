PLAYER GUIDE

HOW TO PLAY

Stay inside the safe zones, work with your team, and watch the ping timer.

1. Set up a match

  1. Create a lobby and share its code with friends, or join a friend's lobby.
  2. The host adds players to the lobby.
  3. Choose 1, 2 or 3 hunters.
  4. Set the runner ping interval to 2, 3, 4 or 5 minutes and choose how long each ping lasts.
  5. On the map, the host can add any number of square, circle and triangle safe boundaries. Click the map to place each shape.
  6. Start the match when enough players have joined.

2. If you are a runner

  • Your live map shows other runners as green circles.
  • Hunters' live positions are hidden from runners.
  • Use the runner team chat to coordinate with other runners.
  • Stay inside at least one green safe boundary. Leaving every safe zone displays an outside-area warning.
  • During a scheduled ping, hunters temporarily receive runner locations for the duration set by the host.

3. If you are a hunter

  • Your live map shows your hunter teammates with red skull markers.
  • Runner live positions are hidden between pings.
  • When a scheduled ping begins, runner locations are revealed for the configured ping duration, then hidden again.
  • Follow the map information to find runners. Respect the safe-zone rules configured for the match.

4. Safe boundaries

  • Square, circle and triangle shapes can be placed on the map.
  • You can add multiple safe zones; being inside any one of them counts as inside a safe area.
  • The lobby host manages boundaries. Place them before the match begins when possible.
  • Location sharing requires the player to grant location permission and use a device/browser that supports geolocation.

5. Settings and profiles

  • In Settings, choose a background theme: Forest Classic, Darkgreen + Lime, Rose Garden, Midnight, Berry Bloom or Moss & Gold.
  • Adjust sound volume from 0 (silent) to 10 (maximum).
  • Your profile tracks hunter wins, runner wins, total wins, games played and winning streak when match results are recorded.

Important note

The game is still being developed. Online play depends on a correctly configured Supabase project and its database policies/migrations. A map warning is not the same as secure server-side elimination, and ping/location visibility should be tested with multiple accounts before relying on it in a real match.
